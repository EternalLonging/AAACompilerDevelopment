# 语义分析

检查声明、类型、左值、函数调用和控制语句；绑定符号并标注 AST。

入口只接收当前解析器成功生成、尚未分析过的 AST。解析器保证节点种类、孩子顺序、非空和树高，语义阶段不重复校验这些结构。

保留名字查找、作用域、类型、初始化、函数调用、返回路径、循环上下文和输入输出格式检查。语义阶段把隐式转换目标记入原节点的 `converted_type`，不新增节点、不改变孩子顺序，并使用内部 `Address` 表示数组参数和输入地址。

不再兼容手工损坏的 AST、函数前置声明、结构体前向声明、位运算、自增自减和逗号表达式。源码支持范围不变，见 [语言范围](../../docs/公共约定/语言支持范围.md)。`same_type` 仍服务于符号表和 IR，类型池仍负责结果的生命周期。
