# 当前文法与约束

116 条产生式，56 个非终结符，0 个预测冲突格。

正式解析器采用分析栈、语义值栈和 LL(1) 预测表。`tools/generate_parser_tables.py` 中的 GRAMMAR 同时生成运行表、FIRST/FOLLOW、SELECT 与 Excel 资料；产生式完成后消费右部语义值并压回一个结果，直接构造 AST，保持节点和孩子顺序。文法直接区分函数定义、变量和成员声明；只允许一维数组、非空具名结构体和具名形参，不接受函数原型、裸类型声明或嵌套声明符。

开始符号为“程序”；空源码允许，`END_OF_FILE` 是输入结束标记，不在产生式右部。FIRST 的可空性单独显示，FOLLOW 不含 ε。预测表采用非空格清单，遗漏的组合为错误格；同一格出现两个候选式时生成器立即报错。语法阶段先构建赋值 AST，目标是否为可修改左值由语义阶段统一检查；文法不代替字面量值和语义检查。

## 上下文约束

| 编号 | 类别 | 条件 | 实现 |
|---|---|---|---|
| C01 | 数组长度 | INT_LITERAL 的值必须为可表示的正整数；对象长度推断和越界检查属于语义阶段。 | `declarator()` |
| C02 | 字面量 | 整数不接受后缀，浮点不接受 L 后缀；字符和字符串由语义阶段解码。 | `unary()` |
| C03 | 赋值左部 | 语法阶段只构建赋值 AST；目标是否为可修改左值由语义阶段 assignment() 统一检查。 | `expression()` |
| C04 | 名字和类型 | 声明可见性、重名、结构体布局、赋值和调用类型兼容由语义阶段检查。 | `declaration()` |
| C05 | 控制流 | break/continue 所在循环、return 所在函数和返回类型由语义阶段检查。 | `statement()` |
| C06 | AST 交接 | 重复后缀按从左到右建立 AST；节点类型、孩子顺序和类型归属保持公共接口约定。 | `finish()` |
| C07 | 首次出错停止 | 预测表空格或终结符失配时报告第一条错误并立即退出，不交付成功 AST。 | `expected()` |
