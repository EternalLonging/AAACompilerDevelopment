# 当前文法与约束

127 条产生式，60 个非终结符，3 个预测冲突格。

依据当前 `parser.cpp` 整理。正式算法是递归下降和表达式优先级攀升；FIRST/FOLLOW/SELECT 与预测表只对本文的文法骨架计算。上下文约束、Token 原文限制和 AST 折叠规则仍由实现检查，不能仅凭预测表认定源码合法。

开始符号为“程序”；空源码允许，`END_OF_FILE` 是输入结束标记，不在产生式右部。FIRST 的可空性单独显示，FOLLOW 不含 ε。预测表采用非空格清单，遗漏的组合为错误格；冲突格保存所有候选式。

## 上下文约束

| 编号 | 类别 | 条件 | 实现 |
|---|---|---|---|
| C01 | 类型说明 | 必须且只能出现一个基础类型；const 可重复，可在类型前后出现。单独 const 不构成类型。 | `specs()` |
| C02 | 仅类型声明 | 只有本条实际带完整 struct 定义时才能省略声明符；struct S; 被拒绝。 | `declaration()` |
| C03 | 函数定义 | 声明符为函数且后接块时，只能在顶层并作为本条第一个声明符；函数声明和原型被拒绝。 | `declaration()` |
| C04 | 定义形参 | 函数定义中的每个形参都必须具名。空列表或单独 void 表示无形参。 | `declaration()` |
| C05 | 结构体 | 定义必须具名且至少有一个成员；标签解析与先定义要求在语义阶段完成。 | `specs()` |
| C06 | 结构体成员 | 成员须有名字，不能有初始化、函数或位域；成员类型不能内联定义 struct。 | `declaration()` |
| C07 | 数组 | 同一声明符最多一层数组；已写出的长度须为正整数字面量、无 U/L 后缀且可表示，省略长度交给语义推导或拒绝。 | `declarator()` |
| C08 | 类型层次 | 函数不能返回数组或函数；数组元素不能是函数或 void。 | `build_type()` |
| C09 | 形参类型 | 形参不能内联定义记录类型、不能按值传 struct、不能是独立 void；不支持省略号。 | `declarator()` |
| C10 | 函数返回 | 不支持 struct 返回值。变量声明中的 void 等合法性仍由语义阶段检查。 | `declaration()` |
| C11 | 块与控制体 | 同一块中声明在语句前；if、else、while、for 的体必须为块。else if 要嵌入 else 的块。 | `block()` |
| C12 | for 初始化 | 三部分可为空；初始化只能是表达式，不能是声明。 | `statement()` |
| C13 | 赋值目标 | 赋值左部须具一元表达式形状或来自括号；a+b=1 语法拒绝，(a+b)=1 通过语法后由语义检查左值。 | `expression()` |
| C14 | 表达式树 | 尾部递归只是消除左递归的文法写法；实现把二元运算折叠为左结合，赋值右结合。 | `expression()` |
| C15 | 取地址与调用 | 前缀 & 在语法阶段接受，语义仅允许 scanf 输入寻址；调用与下标先构造 AST，再检查直接调用和一维对象。 | `unary()` |
| C16 | 字面量 | 整数 U/L 后缀和浮点 L 后缀语法拒绝；相邻字符串合并原文，宽字符等解码限制由语义检查。 | `unary()` |
| C17 | 范围外构造 | 不支持指针、扩展类型、存储类别、typedef、union/enum、do/switch/goto/标签、位运算、移位、复合赋值、三目、自增自减、sizeof 和强制转换。 | `statement()` |
| C18 | 循环跳转 | break/continue 的位置由语义检查；文法只识别关键字与分号。 | `statement()` |

## 预测冲突

| 非终结符 | 向前看 | 候选式 | 实际处理 |
|---|---|---|---|
| 标签可选 | ID | P023 / P024 | specs 总是先消费 struct 后的 ID 作为标签；不把它解释成无标签对象声明。 |
| 形参表可选 | KW_VOID | P042 / P043 | declarator 查看 void 后一项：只有 void 后紧接右括号时才作为空形参列表。 |
| 抽象声明符 | LPAREN | P049 / P050 | declarator 查看左括号后的种别：ID、左括号或星号走分组分支；其余按函数后缀处理，星号随后拒绝。 |
