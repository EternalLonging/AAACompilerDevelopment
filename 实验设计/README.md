# 实验设计资料

| 词法分析 | [状态转换图](词法分析/状态转换图/README.md) | 已确认的单张总图、可编辑 drawio、SVG 和预览 |

| 符号表管理 | [建表与查询](../docs/符号表管理/README.md) | 作用域、名字、编号和成员 |

后三部分的设计说明集中在 docs 对应目录。重复词法图、旧状态表和失效交付说明已清理，回溯见 Git 历史及[仓库整理说明](../docs/公共约定/仓库整理说明.md)。
