# 实验设计资料

本目录保存 AAACompilerDevelopment 的词法状态表、类 C89 项目语言的 LL(1) 文法草案、集合、状态转换图和语法分析流程图。

项目目标是类似 C89 的自定义 C 类语言，具体功能和规则以项目需求为准。C89 用于参考，不作为完整标准符合性要求。旧式函数、复杂声明符等在当前文法中属于候选构造，不自动成为必须实现的功能。

## 主要交付物

- [当前实现的 diagrams.net 单张词法总图](diagramsnet_当前词法/README.md)：一张画布包含 90 个唯一状态、47 类字节及全部有效转移；同一状态出边共用主干后分叉。旧资料继续作为历史设计草案。
- [词法状态转换表](AAACompilerDevelopment_词法状态转换表.xlsx)：92 个普通状态、48 类输入字节；另有头文件上下文表。
- [FIRST / FOLLOW / SELECT 与预测分析表](LL1与图示/C89_LL1集合与预测分析表.xlsx)：包含候选文法和冲突分析。
- [词法状态转换图](LL1与图示/词法状态转换图.pdf)：采用圆形状态、双圈接受状态及带输入标签的有向边。
- [语法分析流程图](LL1与图示/语法分析流程图.pdf)：项目递归下降设计及预测表驱动教学流程。
- [交付说明](LL1与图示/交付说明.md)：语言范围、使用约束及校验结果。
- [矢量图及 DOT 图源](LL1与图示/矢量图/)：含完整普通 DFA 和可读分图。

词法推导依据提交 `589ac50d8602fc926577316e5b6514fba5e242a3` 的规则快照。本目录属于设计与辅助验证资料，正式词法和语法模块的实现与联调以仓库代码和接口规范为准。
