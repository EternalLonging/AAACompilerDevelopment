# 清晰版词法状态转换总图

用户认为上一张完整 DFA 总图“线太乱”。本版采用参考书第二章的正常识别讲解方式，保持**一张画布、一页 PDF**，用一条起始分派主干将各类单词横向展开。各分支内部使用局部接受状态，数值后缀和指数不再跨区汇合；字符串、字符、数字、注释和运算符分别占用连续区域。

优先查看 `词法状态转换总图_清晰版.pdf`。`词法状态转换总图_清晰版.drawio` 是原生可编辑文件；网站中通过“文件 → 从设备打开”使用。`词法状态转换总图_清晰版.svg` 为同一图形的矢量预览。

## 必须区分的两种图

本版为**正常词法识别的教学总图**，使用序列宏边和局部重复的等价接受状态，允许同一个输入进入不同规则候选。它不是原 Excel 的逐字节确定型 DFA；Q 状态编号仅属于本图，不与原 S 状态编号逐项对应。

宏边在图下有明确展开说明，例如 `数字+` 表示至少一位数字，`L?` 表示可选 L，`T` 为合法转义尾部。错误分支不再连到总图中，而是在图下统一说明。实际编译器仍以原 Excel 及项目规则处理最长匹配、规则优先级、非法数字和未闭合字面量等错误，不能用本教学子图代替完整扫描器。例如 `08`、`1e+`、`0x`、`1uu` 仍为词法错误。

GitHub 上的完整逐状态资料见 [已有词法状态图册](../LL1与图示/词法状态转换图.pdf)、[矢量图](../LL1与图示/矢量图/) 和 [词法状态转换 Excel](../AAACompilerDevelopment_词法状态转换表.xlsx)。这些资料覆盖 92 个普通状态、7 个头文件状态及全部有效转移。本版选择更易阅读的表达方式，不能宣称具有同样的逐转移覆盖证明。本地另保留 `../状态转换图_单张总图/` 的完整大画布版本作历史资料，未随本次清晰版上传。

## 本版核验

- drawio 为 1 个 diagram，PDF 为 1 页；圆圈、双圈、连线和标签均为原生编辑对象。
- 48 种固定符号均覆盖，包括复合赋值、移位、预处理符号和省略号。
- 重新读取保存的 drawio，106 条可见路径的端点及文本标签与图形数据一致。
- 将宏边解释为其明确正则，270 个合法完整单词的路径与原 DFA 接受结果对应；10 个典型非法完整单词不能被正常子图完整接受。该检查不证明实际扫描时错误吞入、回退、优先级或与完整 DFA 等价。
- PDF 已渲染检查文字、圈、箭头和各区域的间距。图纸较长，阅读时放大查看，打印时可使用长图或大幅纸张。
