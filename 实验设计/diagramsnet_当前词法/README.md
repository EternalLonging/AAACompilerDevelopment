# 当前词法状态转换图

根据 2026-10-14 拉取的 `origin/main`（`acb315c`）及当前 `lexer/patterns.json` 绘制。图稿已在 [diagrams.net](https://app.diagrams.net/) 的原生编辑器内打开，使用其 ELK 布局排版，再由网站保存为可编辑 XML 并导出 SVG。

打开 `词法状态转换图.drawio`：网站选择“文件 → 从设备打开”。每个圆圈、双圈、箭头及文字均可编辑。也可以双击本目录的 `打开网页编辑.html`，再点击按钮，直接将图稿带入该网站。SVG 为对应页面的矢量预览。

## 阅读顺序

- 00 页说明扫描约定，01–04 页列出 S0 的完整首字节分派。
- 05–12 页分别绘制空白与标识符、整数、小数与指数、十六进制与后缀、字符串、字符、注释以及运算符与分隔符。
- 13 页列出 C00–C46 的精确字节集合；箭头上的连续类别编号可写成范围。
- 14 页列出所有状态的接受动作。双圈包括 Token、skip 和 error；错误候选也可能继续读入并转到合法状态。

虚线状态是同一个 S 状态的跨页副本，点击可跳到后续转移所在页。每条箭头消耗一个字节；没有画出的转移对应 `-1`，表示本次匹配停止。图中没有序列宏边或头文件上下文状态。

最长匹配结束后再执行最后接受状态的动作；同长按规则顺序。识别完整 ID 后查 32 个关键字。EOF 由扫描驱动生成，不是输入字节的 DFA 状态。当前词法仍识别 C89 形式，语法和语义会进一步拒绝 MiniC 范围外的写法；范围以 `docs/frontend.md` 为准。

## 核对结果

- 网站保存后的 15 个页面包含 90 个状态，47 类字节，178 组有向箭头，共 5,078 条有效的逐字节转移。
- 每条转移及接受动作均与从当前规则重新推导的 DFA 一致；没有漏掉自循环、错误转移或添加额外转移。
- 16 项词法规则检查通过，已有 C++ 词法探针与独立 Python 正则的 3,394 个对照用例通过；GitHub 最新提交的 DFA 表与规则一致。
- 网站导出的 SVG 和字符串、数字、注释等页面已作视觉检查。
