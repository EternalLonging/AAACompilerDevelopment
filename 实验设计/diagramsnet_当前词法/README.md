# 单张词法状态转换总图

2026-10-14 根据当前 `lexer/patterns.json` 将各类状态合并到一张画布。图稿已在 [diagrams.net](https://app.diagrams.net/) 原生编辑器内打开、保存并导出 SVG；绘图依据的 `main` 为 `ae1414d`，词法规则与当前实现一致。

双击 `打开网页编辑.html`，点击按钮即可将总图直接带入网站。也可以在网站选择“文件 → 从设备打开”，打开 `词法状态转换图.drawio`。SVG 为完整矢量总图，PNG 为整图预览，`共用出边_局部.png` 是同一张图的运算符区域截取。

## 图形结构

- 只有一个 diagram、一张画布；90 个 S 状态各出现一次。起始分派、字符串、字符、注释、数字、运算符、分隔符和输入集合说明都在这张图中。
- 同一状态的出边使用同一个圆圈出口，先共用一段主干，再按输入条件分叉；S0 的分派主干分别延伸到左右识别区域。
- 布局按识别类别安排区域；折线避开状态圆圈，优先复用同一状态的已有路径。输入标签放在分叉附近，并避开圆圈和其他标签。
- 双圈表示接受状态，包括绿色 Token、青色 skip 和红色 error。错误候选仍可能继续转为合法状态。
- 短输入直接标注字符；C00–C46 表示图下的字节类别。较长输入集合写成 B01 等缩写，精确含义也列在同一画布下方。每条边只读取一个字节。

图中保留全部有效转移和自循环。未画出的转移对应表中的 `-1`，表示本次匹配停止。最长匹配结束后执行最后接受动作；同长按规则顺序。识别完整 ID 后查 32 个关键字。EOF 由扫描驱动生成，不是字节 DFA 的状态。

当前词法仍识别 C89 形式，语法和语义会进一步拒绝 MiniC 范围外的写法；范围以 `docs/frontend.md` 为准。

## 核对结果

- 网站保存后的单张总图：90 个唯一状态、178 组箭头、5,078 条有效字节转移；所有转移和接受动作均与当前 DFA 一致。
- 38 个具有多个目标的状态均使用相同出口和相同第一拐点，出边主干实际重合；不是为各条出边分配不同端口。
- 全部 178 个输入标签与边的数据一致，没有遮住状态圆圈或与其他输入标签重叠。
- 网站导出的图已检查共用主干、数字分支、状态圆圈和标签。此前的 15 张分图预览已被单张总图取代。
