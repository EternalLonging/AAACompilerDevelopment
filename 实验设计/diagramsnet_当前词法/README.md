# 参考图样式的单张词法总图

2026-10-14 按用户提供的图样重绘：一条左侧起始主干向下分派，各类识别从左向右展开。采用黑白圆圈、双圈接受状态、上方弧形自循环和下方局部返回线。全部 12 类识别在同一张画布内，字符串、字符、整数、浮点、注释、运算符和分隔符都有独立的连续区域。

双击 `打开网页编辑.html` 并点击按钮，即可将整图直接带入 [diagrams.net](https://app.diagrams.net/)。也可在网站选择“文件 → 从设备打开”，加载 `词法状态转换图.drawio`。图稿已在网站原生编辑器内打开、保存并导出 SVG。

- `词法状态转换总图.svg`：完整矢量总图，放大后清晰。

## 图形与规则

同一起始状态的分派边重叠共用左侧主干。内部自循环画成上方弧线，转义返回边沿下方局部返回，运算符和数字后缀在当前分支完成接受，避免跨区域汇合。

输入直接标注为空格、字母、数字、引号、合法转义等。`Cs`、`Cc`、`E`、`T`、`H` 的含义在图下说明，`数字+`、`L?`、`0x / 0X`、`CRLF` 为读取序列的宏边。Q 编号用于本图；同一输入可以进入多个正常规则候选。本图表达正常词法识别，错误处理仍由项目扫描器负责。

沿用仓库中的参考图源并按当前 `lexer/patterns.json` 核对。旧图的 `#`、`##` 和头文件上下文已不属于当前规则，因此本图去掉这些旧分支，保留其余 Q 编号以便与参考图对照。

- 1 张画布，76 个状态，98 条识别路径，15 个弧形自循环；25 条起始分派边共用同一个主干。
- 图中所有端点、输入标签、路径点、状态位置和双圈接受状态均与图源核对；网站保存后再次验证。
- 将图中的宏边展开为字节 NFA，与当前正常规则的 DFA 做状态对穷尽比较：133 个可达状态对的接受类别全部一致，覆盖全部 256 种输入字节和所有完整输入序列。

- 正常语言核对不包含错误候选竞争、回退和扫描驱动。例如 `08`、`1e+`、`0x`、`1uu` 仍按当前规则报告词法错误。
