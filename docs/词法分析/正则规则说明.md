# 词法分析正则规则

规则文件是 [src/词法分析/词法规则.json](../../src/词法分析/词法规则.json)，生成结果是 `lexer_dfa.hpp`。扫描器使用最长匹配；长度相同时按规则文件顺序决定优先级。每次编译最后输出一个 `END_OF_FILE`。

## 标识符和关键字

标识符由 ASCII 字母或下划线开头，后面可以跟字母、数字和下划线。当前关键字为：

```text
int float char struct void return if else while for break continue
```

`main`、`printf` 和 `scanf` 是普通标识符。关键字查询在完整标识符识别后进行，因此 `int32` 仍是一个 `ID`。

## 字面量

- 整数支持十进制、八进制和十六进制，原文保存在 `INT_LITERAL`。
- 浮点数支持小数点和指数，原文保存在 `FLOAT_LITERAL`。
- 字符串和字符常量支持常用转义，原文保存在对应 Token。
- 相邻字符串分别输出 Token，由语义阶段拼接和解码。

## 运算符和分隔符

当前 Token 表覆盖算术、比较、逻辑、赋值、取地址、函数调用、数组下标、结构体成员访问以及括号、花括号、方括号、分号和逗号。具体名称以 `include/minic/interface.hpp` 的 `TokenType` 为准。

## 空白、注释和错误

空白、换行、单行注释和块注释只更新源码位置，不产生 Token。非法数字、字符串、字符常量、未闭合注释和其他无法匹配的字节会产生词法诊断；扫描器跳过错误内容后继续，诊断数量达到上限时停止。

规则检查：

```powershell
python tools/check_lexer_patterns.py
python tools/generate_lexer_dfa.py --check
python tools/generate_lexer_tables.py --check
```
