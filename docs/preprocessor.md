# 预处理接口与范围

预处理可独立运行，不依赖词法和语法模块。接口位于 `include/minic/preprocessor.hpp`，实现位于 `src/preprocessor.cpp`。

`preprocess(source, filename, loader)` 返回展开后的源码、每行原始文件和行号、诊断。调用者通过 loader 提供头文件内容，参数是头文件名和包含它的文件名，找不到时返回 `std::nullopt`。模块不自行读取磁盘或提供系统头文件。

`compile_preprocessed(source, filename, target, loader)` 先预处理，再走既有总控；预处理失败不会调用词法。原 `compile` 接口保持直接编译行为。正式词法与语法已接入总控，宏和头文件到真实源码编译的链路已有 frontend_test 验证。

| 功能 | 当前行为 |
|---|---|
| 对象宏、函数宏 | 按预处理单词替换并重扫描；固定参数、嵌套实参；普通参数先展开，字符串化/拼接参数保留原文；递归宏不无限展开 |
| 字符串化、拼接 | `#参数` 合并实参空白并转义引号；`##` 合并左右单词、处理空实参，结果须为一个预处理单词；拼接后的名字继续展开 |
| 跨替换边界重扫描 | 宏别名可接上源码括号，如 `ALIAS(2)`；按每个单词保存禁用宏，处理宏体与后续实参相接的情况 |
| 字面量和数字 | 字符串、字符字面量及数字 token 内的宏名字不展开 |
| 注释、续行 | 移除行注释和块注释；反斜杠换行先拼接；注释按空白分隔 token |
| 条件 | if、ifdef、ifndef、elif、else、endif、defined；未定义名字取 0 |
| 条件表达式 | 十进制/八进制/十六进制整数、L 后缀、括号、算术、比较、位运算、逻辑及三目运算；按优先级执行，逻辑和三目短路 |
| 包含 | 引号或尖括号文件名，由同一 loader 读取；共享宏表，可用包含守卫阻止递归重复 |
| 其他 | undef、error；冲突定义、缺失参数/括号/endif、找不到头文件有中文诊断 |

条件表达式采用有符号 32 位模型，溢出、除零和非法移位报错；不支持 unsigned 条件常量和字符条件常量。负数右移采用算术右移。此模型不能作为完整 C89 预处理整数规则。

输出与单个输入文件上限 16 MiB，包含深度最多 64，宏展开深度最多 128、数量最多 100,000，条件表达式递归深度最多 128。

行映射保留指令和被跳过分支的空行；续行对应第一物理行。头文件内容单独记录文件和行号。总控映射 Token 及词法诊断后再交给语法；列号置 1，字节偏移置 0，**只保证原始行号，不能保证宏展开后的精确列号、字节位置和跨文件范围**。基于字节偏移的补全接口应使用直接编译的单文件结果。

尚不支持变参宏、跨逻辑行的宏调用、预定义宏、pragma、line、系统头文件和三字符组。遇到不支持的指令明确报错；宏替换和重扫描已覆盖本文行为，但未声称通过完整 C89 预处理一致性测试。头文件的路径搜索策略由调用者决定。

验证：`tests/preprocessor_test.cpp` 覆盖宏、字符串化、空参数拼接、别名重扫描、跨宏边界、字面量保护、条件算术与短路、递归守卫、行映射和错误边界；`tests/compiler_flow_test.cpp` 验证总控停止和头文件 Token 行号映射。开发验证还对照 GCC 的 12 组嵌套、递归、拼接和字符串化用例，输出单词一致。
