# 命令行使用

```powershell
build/ninja/minic.exe <tokens|parse|symbols|check|ir|run> <源文件>
```

命令直接从源码执行词法、语法、语义和中间代码阶段。编译失败时停止后续阶段，诊断写入标准错误。运行成功返回 main 的返回值，编译或执行失败返回 1。

```c
int main(void) {
    const int N = 5;
    printf("value = %d\n", N * 2);
    return 0;
}
```

保存为 demo.c 后执行 `build/ninja/minic.exe run demo.c`，输出 `value = 10`。printf 和 scanf 是内建函数，无需头文件。宏、头文件包含、union 和 enum 已移除，范围见 [语言支持范围](../公共约定/语言支持范围.md)。
