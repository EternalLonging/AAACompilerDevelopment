## 复验方式

```powershell
cmake -S . -B build/cmake -DCMAKE_CXX_FLAGS=-Werror
cmake --build build/cmake
ctest --test-dir build/cmake --output-on-failure
python tools/test_acceptance.py build/cmake/minic.exe --report build/acceptance.json
# 可选：复核八个正常综合程序的预期输出
python tools/test_acceptance.py build/cmake/minic.exe --reference-gcc 'D:/G++/MinGW/bin/g++.exe'
```

脚本默认执行 26 项，加入 GCC 参考时执行 34 项。所有检查必须通过才返回 0；失败会打印对应项目与实际差异。自动化脚本在临时目录生成程序并清理，不向仓库提交构建产物或临时程序。
