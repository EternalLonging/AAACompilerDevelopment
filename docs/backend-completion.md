## 目标模型

| 类型 | 字节大小 / 对齐 |
|---|---|
| char | 1 / 1 |
| short | 2 / 2 |
| int、long、float | 4 / 4 |
| double、long double、指针 | 8 / 8 |

char 默认有符号，支持显式 unsigned。long double 按 64 位 double 执行。数值存储使用小端表示；无符号整型按位宽回绕，有符号溢出报错。原 MiniC 的 char/int/float 隐式缩窄限制和无后缀浮点按 float 的约定保留，不能据此宣称完全符合 C89。

union 所有成员偏移为 0，整体大小按最大成员大小和对齐补齐。数值叶子保存共享字节，指针保存对象身份元数据；**禁止把指针表示当数值字节读取，反向也禁止**。字符串字面量按内容共享只读对象。聚合传参、赋值和返回均拷贝值，不让形参修改影响调用者。

新增四元式：`faddr(function, -, pointer)` 取函数地址；`callind(pointer, count, result)` 间接调用，签名必须固定且一致；`tempaddr(temporary, -, address)` 定位当前调用帧的临时聚合对象。间接调用会先保存被调指针，再计算实参。原有四元式与公共 AST 节点保持兼容。

printf/scanf 仍要求字面量格式串，支持 d/u/x/o/f/c/s 和匹配的 h/l/L 修饰。printf 宽度、精度和动态格式串尚不支持；scanf 宽度目前只用于 %s，必须为正且目标容量能容纳结束零。输入超出容量、没有终止零、修改只读字面量均报错。

## 交付边界
