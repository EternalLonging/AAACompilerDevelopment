# 数组、结构体、指针与后续模块交接

日期：2026-10-09。本文记录 M1 之后实际落地的功能。词法、语法仍由其他同学交付；以下均通过符合公共合同的手动 AST 验证，不代表已经可以直接编译 C 源文件。

## 1. 已实现的功能

| 内容 | 语义检查和执行行为 |
|---|---|
| 数组 | 一维、多维数组；固定长度；由初始化列表或字符串推导最外层长度；每维下标检查 |
| 结构体 | 标签前向声明、定义、嵌套成员、含数组或指针的成员、成员寻址、整体值拷贝 |
| 初始化 | 嵌套 InitList；聚合未列出的部分补零；窄字符串初始化 char 数组 |
| sizeof | 类型或表达式求大小；检查表达式类型后折成整数；不执行表达式副作用 |
| 控制流 | do-while、switch/case/default、贯穿、break、continue、条件表达式 `?:` |
| 对象指针 | 取地址、解引用、赋值、空指针、条件判断、比较、指针传参和返回值、结构体指针成员访问 |
| 数组与指针 | 普通数组转首元素指针；数组形参调整为指针；指针下标；整型偏移、自增自减、复合偏移、同数组差值和大小比较 |
| typedef | 普通名字表登记类型别名；别名可用于数组、结构体、指针及函数签名；内部块可遮蔽外层别名 |
| enum | 枚举标签、显式整型常量、自动编号、引用前面的枚举项；枚举对象在当前目标模型中按 int 执行 |
| 标签与 goto | 每个函数独立检查标签；前向或后向跳转；缺失和重复标签诊断；执行步数限制仍生效 |
| 整数运算 | `& | ^ ~ << >>`、对应复合赋值和 `%=`；逗号表达式从左到右求值 |
| 静态存储 | static 全局对象、static 局部对象、static/extern 函数声明；静态局部对象初始化一次并保留值 |
| 常量折叠 | 无副作用的整型和浮点表达式；保留每一步 float 舍入；溢出或除零时保留原 IR，让运行器明确诊断 |

M2 的后续流程已实现。M3、M4 已接入表内列出的部分，完整 C89 仍未完成。结构体函数传值/返回、临时聚合值成员访问、union、扩展数值类型、函数指针、外部对象链接、预处理和标准库尚待后续扩展。

## 2. 类型与存储约定

目标布局固定为 char=1/1、int=4/4、float=4/4、对象指针=8/8（大小/对齐，单位字节），不取宿主 C++ 的 sizeof。结构体逐成员对齐，末尾补齐到最大成员对齐。数组大小为元素大小乘长度。单个对象最多 16 MiB，类型嵌套最多 128 层。

数组的 Array 类型每层只保存这一维长度。只推导最外层缺失长度；内层长度必须确定且大于零。初始化列表按层明确嵌套，不实现 C 的省略内部花括号、指定初始化或变量长度数组。char 采用 8 位有符号模型；字符串按窄字节处理，不能据此宣称支持宽字面量或任意 Unicode 字符。

未初始化的全局和 static 局部对象先置零。静态初始化只允许数值常量表达式和静态对象的固定地址，不调用函数。普通局部对象每次执行声明时重置为未初始化；部分聚合初始化先把整个对象置零，再写指定项。

聚合存储按字节偏移保存叶子值。结构体赋值和函数实参快照复制值，不共享聚合容器。默认初始化状态不同的子聚合拷贝最多显式展开 1,000,000 个叶子，超限报告运行错误。

const/volatile 向数组元素和结构体成员传播。兼容指针可增加所指对象的限定符，不能隐式丢弃；多层指针采用严格结构比较，不允许 `int**` 直接转 `const int**`。当前不实现任意指针强制转换、void* 通用转换或函数指针。register 对象不能取地址，register 数组不能退化为指针。

## 3. 指针边界与生命周期

地址保存根对象、调用帧编号、字节偏移、所指类型和可移动范围。数组指针只能在同一个数组的起点至尾后位置内移动；单独对象按长度为 1 的数组处理。尾后位置可形成、比较和相减，不能解引用。直接数组下标始终要求 `0 <= i < length`；形成尾后指针应使用 `a + length`。

指针差值和大小比较只允许同一根对象、同一数组范围。相等比较可比较不同对象。空指针参与算术、解引用，或读取未初始化指针都会报告运行错误。返回已结束函数内普通局部对象的地址后再解引用会报错；static 局部对象地址在该次 run 中保持有效。

目前地址生命周期按调用帧检查，尚未按每次进入/退出内部块分配独立对象身份。因此不能把这些检查当作完整 C 对象生命周期验证。也未实现动态内存分配、释放和真实机器地址模型。

scanf 除 `&x` 外可接收类型匹配的可写数值对象指针，包括数组元素、结构体成员地址。printf/scanf 的格式仍要求字面量；printf `%s` 仍只支持字符串字面量，scanf `%s` 及宽度、长度修饰、动态格式串尚未支持。

## 4. AST 合同

公共字段、节点枚举及原孩子顺序不变，继续按 [interface.md](interface.md) 构造。新增接入要求如下：

- StructDef、EnumDef、TypedefDecl、Label、Goto 使用既有节点。无成员 StructDef 表示前向声明；EnumDef 至少包含一个 EnumMember。
- 声明类型用 TypeInfo 表达：Struct.name 是标签，Named.name 是别名，Pointer.base 是所指类型，Array.base 是下一层。
- ArrayAccess 的两个孩子为对象和整型下标；对象可以是数组或对象指针。
- MemberAccess.name 是成员名，只有一个孩子。结构体对象直接查成员；结构体指针自动降成 `(*p).m`，解析器也可显式提供 UnaryOp `*`。
- InitList 的孩子按元素或成员声明顺序保存；Case 是 `[整型常量表达式, 语句]`，Default 是 `[语句]`。
- DoWhile 是 `[循环体, 条件]`，Conditional 是 `[条件, 真值, 假值]`。
- Sizeof 有 declared_type 时无孩子；没有 declared_type 时只有表达式孩子。语义阶段将其改成 IntLiteral。
- 普通数组的值上下文由语义插入 ImplicitCast；sizeof、取地址和数组初始化保持数组类型。数组形参签名和 ParamDecl 会统一调整为指针。
- 枚举项使用 Identifier 引用；语义绑定后改成整型字面量，仍在符号表和记录表保留枚举项信息。

AST 只分析一次。语义阶段会写回绑定、类型并插入转换；不得再次把已分析的树交给 analyze。

## 5. 四元式合同

| op | arg1 | arg2 | result | 含义 |
|---|---|---|---|---|
| zero | - | - | 对象 `%sID` | 初始化整个对象为零 |
| load | 地址 | - | 值临时量 | 从子对象读取数值、指针或聚合值 |
| store | 值 | - | 地址 | 写入子对象，聚合采用值拷贝 |
| indexaddr | 指向数组的地址 | int 下标 | 元素地址 | 按这一维元素步长寻址并检查范围 |
| memberaddr | 指向结构体的地址 | 十进制成员偏移 | 成员地址 | 按成员表校验偏移和类型 |
| decay | 指向数组的地址 | - | 首元素指针 | 保留这一层数组的移动边界 |
| ptradd / ptrsub | 对象指针 | 整型偏移 | 对象指针 | 加减元素数量，不是字节数量 |
| ptrdiff | 左指针 | 右指针 | int 临时量 | 同一数组内相差的元素数量 |
| bnot | 整型值 | - | int 临时量 | 按位取反 |
| `& | ^ << >>` | 整型左值 | 整型右值 | int 临时量 | 位运算和移位 |

指针条件复用 jz/jnz/not，指针比较复用比较指令；空指针由整型零常量通过 cvt 建立。goto 复用 jmp/label，用户标签加 `user_` 前缀，避免与内部标签混淆。switch 先比较和跳转，再按源顺序保留 case 贯穿；嵌套 switch 单独管理标签。

IRProgram.globals 保存所有静态存储对象，包括作用域仍属于函数/块的 static 局部对象。它们的初始化放入 global_initializers，进入 main 前执行一次，函数内不生成 local 或重复初始化。

整型移位数量必须为 0–31；负数左移和超范围左移报错。负数右移在本教学目标中明确采用算术右移。?: 和逻辑运算只执行被选中的分支；常量折叠不执行调用、赋值或对象读取。
