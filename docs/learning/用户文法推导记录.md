## 已确定的变量声明草稿

前置条件：进入“变量声明后续”之前，已经匹配变量类型和第一个变量名。

```text
变量声明后续 -> 数组可选 赋值 变量声明后续2

变量声明后续2 -> "," ID 变量声明后续
变量声明后续2 -> ";"

赋值 -> "=" 表达式
赋值 -> ε
```

“赋值”在本组规则中特指声明时可选的初始化部分，不是独立的赋值语句。
逗号后先匹配新变量名 ID，再复用“变量声明后续”；整条声明的分号在最后一次展开时匹配。

## 后续确定的改名与规则

用户将“数组可选”改名为“数组定义”。前面的“变量声明后续”同步使用新名称。

```text
数组定义 -> "[" 数组长度 "]"
数组定义 -> ε

数组长度 -> INT_LITERAL
数组长度 -> ε

形参 -> 变量类型 ID 数组定义

变量声明 -> 形参 赋值 变量声明后续2

变量声明后续 -> 数组定义 赋值 变量声明后续2
变量声明后续2 -> "," ID 变量声明后续
变量声明后续2 -> ";"
```

“形参”在上述变量声明规则中复用的是一个参数的类型、名字和数组部分，不是整个函数参数列表。
普通类型的示例：`int a = 3, b[5];`。第一个变量通过“形参”匹配，后续变量沿用声明开头的类型。
默认参数功能已讨论，用户决定不加入；形参声明不接受 `= 表达式`。函数体内仍允许给形参赋值。

## 函数形参、代码块与语句（2026-11-18 更新）

```text
函数形参 -> 形参 函数形参2
函数形参 -> KW_VOID
函数形参 -> ε

函数形参2 -> "," 形参 函数形参2
函数形参2 -> ε

代码块 -> "{" 局部声明序列 语句序列 "}"

局部声明序列 -> 变量声明 局部声明序列
局部声明序列 -> ε

语句序列 -> 语句 语句序列
语句序列 -> ε

语句 -> 表达式2 ";"
语句 -> 返回语句
语句 -> 代码块

返回语句 -> KW_RETURN 表达式2 ";"

表达式2 -> 表达式
表达式2 -> ε
```

用户决定统一使用“表达式2”表示可省略的表达式，因此删除单独的 `语句 -> ";"` 分支，不再另设“返回值可选”。
普通“表达式”仍不能为空；赋值号右侧继续使用普通“表达式”，不接受 `a=;`。
源码分号使用半角 `;`。

## 后续确认的控制语句

以下保留用户对非终结符的命名；例如非终结符 `if` 表示完整条件语句，而终结符 `KW_IF` 只匹配关键字。

```text
语句 -> while
语句 -> if
语句 -> for
语句 -> KW_BREAK ";"
语句 -> KW_CONTINUE ";"

while -> KW_WHILE "(" 表达式 ")" 代码块

if -> KW_IF "(" 表达式 ")" 代码块 else2
else2 -> KW_ELSE else
else2 -> ε
else -> 代码块
else -> if

for -> KW_FOR "(" 表达式2 ";" 表达式2 ";" 表达式2 ")" 代码块
```

用户方案包含 `else if`，区别于当前正式项目只接 `else` 代码块的写法。控制体要求代码块；for 初始化不引入变量声明。
for 条件省略时表示真；break/continue 是否位于循环内由语义分析检查。

后缀式、后缀序列与单个后缀的区别已解释，用户确认将这一部分视为完成；上面三种单后缀是对讨论内容的整理。
调用的“实参可选”仍待展开，不能与函数定义的形参混用。项目支持相邻字符串拼接，主式中的字符串规则在最终整理时补齐。

## 一元式与乘法式（2026-11-18 更新）

```text
一元式 -> "+" 一元式
一元式 -> "-" 一元式
一元式 -> "!" 一元式
一元式 -> 后缀式

乘法式 -> 一元式 乘法式2
乘法式2 -> "*" 一元式 乘法式2
乘法式2 -> "/" 一元式 乘法式2
乘法式2 -> "%" 一元式 乘法式2
乘法式2 -> ε
```

用户选择用“运算符 + 一元式 + 续”表达每个乘法运算。该写法便于将操作数和运算符整理成序列，但尾部仍然右递归。
如果归约时直接递归构造运算节点，依然可能得到 `12 / (3 / 2)`；这组文法本身不会自动保证左结合。
要得到标准左结合 AST，归约动作必须显式按从左到右折叠，确保 `12 / 3 / 2` 构造成 `(12 / 3) / 2`。实现比较时要把这一步的代码纳入复杂度评估。

## 表达式与赋值的复用（2026-11-18 确认）

```text
表达式 -> 逻辑或式 赋值
赋值 -> "=" 表达式
赋值 -> ε
```

用户决定复用声明初始化所用的“赋值”，不再定义“非定义时的赋值”。“赋值”只匹配可选的等号和右侧表达式，本身不包含左侧目标，也不包含分号。赋值目标是否为可修改左值由语义阶段检查，不能将声明中的“形参”误认为所有合法赋值目标。
