# 中间代码生成与执行

`ir.cpp` 的 `generate` 读取语义标注后的 AST 和同次编译的符号表，生成 `IRProgram`：函数分组、四元式、临时量、位置及常量池。符号使用 `%sID`，值常量使用 `%cID`，避免同名对象混淆。

if、while、for 和逻辑短路使用内部跳转标号；break/continue 跳转到对应循环位置。实参从左到右求值并在调用前保存快照。默认进行安全常量折叠，可通过 `IRGenerationOptions` 关闭，用于优化对比。

`constant_pool.cpp` 按类型和值登记、去重；`interpreter.cpp` 的 `run` 检查 IR 合同后执行全局初始化和 main，管理独立调用帧，检查除零、初始化、边界和输入失败。默认步数和调用深度限制见[模块接口](../公共约定/模块接口.md)。当前产物为可解释执行的四元式。
