# 数组、记录与控制流

当前保留功能及语法限制见 [语言支持范围](../公共约定/语言支持范围.md)，公共 AST 合同见 [数据结构与 AST 约定](../公共约定/数据结构与AST约定.md)。

## 数据与存储

数组只支持一维下标、初始化、长度推导和传参。形参数组内部保存首元素地址，因此修改形参数组元素会改变原数组。带标签的 struct 支持成员和对象赋值；变量按全局、局部和形参管理。

源语言布局为 char=1/1、int/float=4/4（大小/对齐，字节）。struct 逐成员对齐并补齐末尾。内部地址占 8 字节，仅用于数组参数和运行时寻址。单对象最多 16 MiB，类型嵌套最多 128 层。

数值与聚合读取检查初始化、对象存活、对齐和边界。数组下标要求 `0 <= i < length`，数组参数使用内部地址表示。

## 控制与输入输出

保留 if/else、while、for、break、continue 和 return。控制体需要花括号；同块先声明再执行，for 变量提前声明。

printf/scanf 格式必须是字面量，只支持 `%d`、`%f`、`%c`、`%s` 和 `%%`。字符串输入会检查数组容量，超长则报错；数值输入用 `&x`、`&a[i]` 或 `&s.member`，只允许可写对象。

## 内部寻址四元式

| 指令 | 作用 |
|---|---|
| addr | 获取变量的内部地址 |
| indexaddr | 按下标定位普通数组元素 |
| offsetaddr | 按下标定位数组形参的元素，检查数组边界 |
| memberaddr | 按成员偏移定位记录成员 |
| tempaddr | 定位临时聚合的成员 |
| decay | 将数组转换为传参或字符串读写所需的内部首元素地址 |
| load / store | 读取或写入地址对应的值 |
| zero | 初始化聚合存储 |

只保留直接 `call`；旧 `faddr`、`callind`、`ptradd`、`ptrsub`、`ptrdiff` 不再生成或执行。实参从左到右求值，调用前保存快照，递归调用使用独立调用帧。

回归涵盖一维数组传参、输入数组元素和成员、字符串输入、结构体赋值、全局和局部存储及运行错误。
