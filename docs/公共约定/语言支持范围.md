# 教学语言范围

## 当前语言范围

- 基础类型为 `void`、`char`、`int`、`float`；`void` 用于函数返回值和空参数列表。
- 支持变量声明、赋值、一维数组、带标签的 `struct`、函数定义和直接函数调用。
- 支持 `if/else`、`while`、`for`、`break`、`continue` 和 `return`。
- 支持加减乘除取余、比较、逻辑运算、括号表达式、数组下标和结构体成员访问。
- 变量初始化使用一个赋值表达式；字符串可以初始化字符数组。
- 同一代码块先声明后写语句；`if`、`while`、`for` 的控制体使用花括号。
- `printf` 和 `scanf` 使用 `%d`、`%f`、`%c`、`%s`、`%%`；输入参数使用 `&变量`、`&数组下标` 或 `&结构体成员`。

## 语法约定

- `struct` 必须带标签并在使用前完成定义，成员按声明顺序保存。
- 数组只使用一维下标，数组形参按首元素地址传递。
- 函数定义直接包含参数列表和函数体；函数调用保存被调表达式及实参的顺序。
- `for` 的三个表达式可以省略，AST 中用 `Empty` 节点占位。
- 字符串和字符常量保留源码拼写，语义阶段负责解码、类型检查和隐式数值转换。

源码经过词法、语法、语义和中间代码阶段后，由解释器执行。各阶段的公共对象和孩子顺序见 [数据结构与 AST 约定](数据结构与AST约定.md)。
