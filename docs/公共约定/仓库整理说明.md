## 以后如何归类

每部分的实现放在 `src/对应部分`，说明放在 `docs/对应部分`，图稿放在 `实验设计/对应部分`；跨阶段规则放在公共支持或公共约定。正式成品只保留一个当前入口，历史设计必须标明版本。新增文件同时更新对应 README 和必要的构建、测试路径。
