# 源码联调说明

当前范围见 [语言支持范围](语言支持范围.md)。同一块先声明后执行，for 使用提前声明的变量，if/else/while/for 的控制体写花括号。

## 正式入口

`compile` 依次调用 lex、parse、analyze、generate；上一阶段失败就停止。`tests/integration_driver.cpp` 链接正式前端，成功后执行真实四元式。清单 [manifest.json](../../tests/integration/manifest.json) 保存输入、输出、main 返回值及拒绝阶段。source_integration 验证 46 份源码夹具。

## AST 孩子顺序

- FunctionDef：先形参节点，最后函数体 Block；`void` 只表示空形参列表。
- Call：先被调函数，再按顺序保存实参。scanf 数值输入的 `&x` 使用 UnaryOp 孩子 Identifier。
- For：固定为初始化、条件、更新、循环体；省略的分量使用 Empty。
- While：条件、循环体。If：条件、真分支，以及可选的假分支。
- MemberAccess：名字保存成员名，唯一孩子是结构体对象。

类型绑定和符号表由语义遍历完成。结构体仍用 StructDef 和 TypeKind::Struct，按 RecordId 绑定身份。typedef、存储类别、do-while、switch 和 goto 已删除，不再生成对应节点或类型。

## 验证

```powershell
cmake -S . -B build/ninja -G Ninja -DCMAKE_CXX_FLAGS=-Werror
cmake --build build/ninja
ctest --test-dir build/ninja --output-on-failure
python tools/test_integration.py --compiler build/ninja/integration_driver.exe
```

正常程序核对完整输出和返回值，错误程序核对最早失败阶段及诊断，失败后不得继续生成或执行。只统一 CRLF/LF；旧功能源码保留为拒绝用例。
