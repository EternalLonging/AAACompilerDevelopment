# 本地图形工作台

构建后运行 `python tools/workbench_server.py --open`，或双击 `start-workbench.cmd`。页面默认在 http://127.0.0.1:8765，只在本机编译和执行。

## 文件与编辑

- Ctrl+N 或「新建文件」创建 `.c` 文件，可使用 `src/demo.c` 等项目内路径。
- Ctrl+S 或「保存文件」保存到电脑。新文件切换、打开或新建其他文件前，必须保存或放弃；取消保存继续留在当前文件。
- 「打开文件」导入 `.c` 或项目 JSON；「保存项目」保存全部源码、编译文件选择及输入。项目只在页面内保存，刷新前请保存到电脑。
- 当前编辑文件和编译文件可分别选择；每次只编译所选 `.c`，其他文件不自动链接。
- 输入 `{`、`(`、单引号、双引号会配对并将光标放在中间。输入已有结束符会跳过，退格可删除空配对。
- Enter 按花括号嵌套层数添加真实 Tab，注释和字面量中的花括号不计入作用域；右花括号退回上一层。

代码自动补全已删除。Ctrl+Space 不请求候选；Enter 和 Tab 只负责换行、缩进。不创建或导入 `.h`，源码中的 `#include` 明确报错。

## 编译结果

「分析」显示各阶段产物，「运行」再解释执行并显示输出和退出码。支持单词表、可缩放 AST、符号表、四元式与常量池、宏展开源码、优化前后对比。点击 AST 节点或诊断可定位源码，语法树可导出 SVG。数据来自真实编译器。

优化对比从同一棵语义树分别生成折叠前后的 IR，并独立执行；两边都成功且输出、退出码相同才显示一致。失败不宣称等价。

每文件最多 256 KiB，输入最多 64 KiB，项目最多 33 个文件；每侧执行最多 100,000 条指令、128 层调用，服务进程限时 15 秒，同时最多两个编译请求。语言范围见 [language-scope.md](language-scope.md)。

`workbench` 和 `workbench_service` 测试数据与接口，`tools/test_workbench_browser.py` 另验证括号光标、缩进、无补全、Ctrl+N/Ctrl+S、保存/放弃/取消、项目导入导出、真实运行、AST 导出和桌面/手机布局。
